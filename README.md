Computer Rental Shop/Internet Cafe

Runtime: Node.js
Server: Node.js
Frontend: HTML / CSS / JavaScript
Project Structure
.
├── Server/           # Backend code (routes, logic, etc.)
├── public/           # Static frontend files served to the browser
├── server.js         # Application entry point
├── package.json      # Project metadata, dependencies, and scripts
├── package-lock.json # Locked dependency versions
└── .gitignore        # Files and folders excluded from Git

**HOW TO USE:**
Start the server.
Open the frontend in your browser.
You can now access the program, with different functions such as Adding a Session, Reserving a Session, and more1
